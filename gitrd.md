# GPU Report

**GPU Report** — консольная утилита для Linux, которая обнаруживает графические
адаптеры, проверяет возможности аппаратного декодирования и кодирования видео,
показывает локализованный отчёт и формирует рекомендации для FFmpeg.

Главный принцип проекта — **достоверность важнее количества найденных
возможностей**. Если поддержку нельзя подтвердить, программа выводит
`UNKNOWN`, а не подменяет результат значением `NO`.

## Возможности

- Обнаружение Intel, AMD, NVIDIA и других PCI-совместимых GPU через Linux sysfs.
- Работа с гибридными системами и несколькими видеокартами.
- Вывод названия GPU, PCI Vendor/Device ID, PCI-пути, драйвера, версии драйвера,
  DRM-карт и render nodes.
- Независимая проверка аппаратного декодирования и кодирования для:
  - H.264/AVC;
  - HEVC/H.265;
  - VP8;
  - VP9;
  - AV1;
  - MPEG-2;
  - VC-1;
  - JPEG/MJPEG.
- Три достоверных состояния: `YES`, `NO`, `UNKNOWN`.
- Диагностика через VA-API, Vulkan, FFmpeg, NVIDIA NVENC/NVDEC,
  `nvidia-smi` и доступные данные NVML.
- Отдельный учёт источников подтверждения для каждого кодека.
- Поддержка профилей, разрядности и форматов пикселей, когда эти данные
  действительно подтверждены.
- Форматы, объявленные только сборкой FFmpeg, помечаются отдельно как
  **не проверенные на конкретном GPU**.
- Рекомендованные диапазоны битрейта и примеры команд FFmpeg только для
  подтверждённых аппаратных энкодеров.
- Unicode TUI на ncursesw с цветными статусами, прокруткой, переключением GPU
  и экспортом XML.
- Обычный текстовый отчёт для скриптов, перенаправления вывода и терминалов без
  ncurses.
- Атомарный экспорт `gpu_info.xml` с проверкой через libxml2 перед заменой
  целевого файла.
- Не требует root для диагностики, не изменяет драйверы и не запускает тестовое
  кодирование или декодирование.

## Поддерживаемые языки

Интерфейс, справка, сообщения об ошибках и TUI доступны на шести языках:

1. Английский — `english` / `en`;
2. Русский — `russian` / `ru`;
3. Японский — `japanese` / `ja`;
4. Корейский — `korean` / `ko`;
5. Упрощённый китайский — `chinese` / `zh`;
6. Испанский — `spanish` / `es`.

Язык можно выбрать явно:

```bash
gpu-report --list-gpu --set-local=russian
gpu-report --get-report --set-local=japanese
```

Если параметр не указан, используются `LC_ALL`, `LC_MESSAGES` и `LANG`.
Английский применяется как резервный язык.

## Быстрая сборка и установка

### 1. Установка зависимостей

Arch Linux:

```bash
sudo pacman -S --needed base-devel cmake pkgconf ncurses libxml2 hwdata
```

Debian/Ubuntu:

```bash
sudo apt update
sudo apt install -y build-essential cmake pkg-config libncursesw5-dev libxml2-dev hwdata
```

Fedora:

```bash
sudo dnf install -y gcc-c++ make cmake pkgconf-pkg-config ncurses-devel libxml2-devel hwdata
```

Необязательные средства расширенной диагностики:

```text
ffmpeg, vainfo (libva-utils), vulkaninfo (vulkan-tools), nvidia-smi
```

Их отсутствие не приводит к аварийному завершению программы.

### 2. Сборка

```bash
make build
```

По умолчанию создаётся Release-сборка в каталоге `build/`.

### 3. Установка без root

```bash
make install
```

По умолчанию программа устанавливается в `~/.local`:

```text
~/.local/bin/gpu-report
~/.local/share/gpu-report/locales/
~/.local/share/doc/gpu-report/
```

Если `~/.local/bin` ещё не находится в `PATH`:

```bash
export PATH="$HOME/.local/bin:$PATH"
```

Системная установка:

```bash
sudo make install PREFIX=/usr/local
```

Дополнительные команды:

```bash
make test
make clean
make help
```

Каталог, тип сборки и число потоков можно переопределить:

```bash
make build BUILD_DIR=out BUILD_TYPE=Debug JOBS=4
```

## Использование

```bash
gpu-report --help
gpu-report --version
gpu-report --list-gpu
gpu-report --get-report
gpu-report --get-report --no-tui
```

Выбор видеокарты:

```bash
gpu-report --get-report --set-gpu 0
gpu-report --get-report --set-gpu 0000:01:00.0
gpu-report --get-report --set-gpu 10de:1341
```

Экспорт XML:

```bash
gpu-report --get-report --export gpu_info.xml
```

В интерактивном TUI экспорт выполняется клавишей `e`.

Навигация по разделам TUI:

- `1`, `o`, `b`, Backspace или Esc — вернуться в **Обзор**;
- `2` или `d` — открыть **Детали**, повторное нажатие возвращает в обзор;
- `3` или `r` — открыть полный **Отчёт**, повторное нажатие возвращает в обзор;
- `4`, `?` или F1 — открыть справку, повторное нажатие возвращает в обзор.

## Использованные библиотеки и технологии

### C++17 и стандартная библиотека C++

Используются для модульной архитектуры, контейнеров, строк, файловой системы,
обработки ошибок и переносимой бизнес-логики. C++17 доступен в современных GCC
и Clang во всех целевых дистрибутивах.

### ncursesw

Широкосимвольная версия ncurses выбрана для интерактивного терминального
интерфейса. Суффикс `w` важен: он обеспечивает корректную работу русского,
японского, корейского и китайского текста, а также обработку размеров терминала,
цветов и клавиш навигации.

### libxml2

Используется для двух задач:

- загрузки XML-каталогов локализации;
- безопасного создания, экранирования, повторного разбора и проверки
  `gpu_info.xml`.

libxml2 выбрана как зрелая системная библиотека, доступная в основных
Linux-дистрибутивах.

### POSIX API

`fork`, `execvp`, `poll`, `waitpid`, файловые дескрипторы и process groups
используются для безопасного запуска диагностических программ без shell.
Благодаря этому пользовательские значения не конкатенируются в команды shell,
а зависшие процессы завершаются по тайм-ауту.

### Linux sysfs и DRM

Каталоги `/sys/bus/pci/devices`, `/sys/class/drm` и устройства `/dev/dri`
используются как основной системный источник для обнаружения GPU, драйверов,
DRM-карт и render nodes. Это не требует изменения конфигурации системы.

### libdl

Динамическая загрузка через `dlopen` позволяет проверить наличие NVML, не делая
проприетарную библиотеку NVIDIA обязательной зависимостью проекта.

### Внешние диагностические инструменты

- `vainfo` — подтверждение профилей VA-API для Intel и AMD;
- `vulkaninfo` — идентификация устройств и проверка Vulkan Video extensions;
- `ffmpeg` — информация о доступных в конкретной сборке энкодерах, декодерах и
  форматах;
- `nvidia-smi` — модель, архитектура, версия драйвера и доступность движков
  Encoder/Decoder;
- `pci.ids` — человекочитаемые названия PCI-устройств.

Эти инструменты запускаются только для чтения информации. Наличие энкодера в
FFmpeg само по себе не считается доказательством поддержки со стороны GPU.
